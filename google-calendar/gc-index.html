Conexión Google Calendar

Esta pantalla sirve para configurar, conectar y validar Google Calendar. La creación de eventos se realiza únicamente desde Agendador o Carga Masiva.

Sin probar

1. Datos de conexión

Primero guarda las credenciales Web y/o Escritorio junto con el Calendar ID. Luego usa Conectar para autorizar Google. Probar conexión valida el acceso, pero no crea eventos.

Nota: Para navegador local, autoriza este origen en Google Cloud Console: http://127.0.0.1:5500 y/o http://localhost:5500.

2. Regla de creación de eventos

Google Calendar queda como canal de sincronización. Para crear un evento, usa el módulo Agendador o Carga Masiva.

Bloqueado: esta pantalla ya no crea eventos manuales ni eventos automáticos de prueba.
