# AgendaJeff 0.0.1

Fecha: 2026-06-28

## Cambios principales

- Base modular de AgendaJeff.
- Shell principal con módulos por iframe.
- Base local JSON.
- Pantallas Inicio, Agenda, Carga Masiva, Ajustes y Diagnóstico.
- Integración preparada con Firebase, Google Calendar, Telegram y Notificaciones.
- Segundo plano y bandeja preparados.
- Manifiesto de versión para GitHub Releases.

## Instalación

- Windows: publicar instalador EXE en GitHub Releases.
- Android: publicar APK manual en GitHub Releases cuando el bloque Android esté listo.

## Regla de actualización

AgendaJeff descarga o detecta versión nueva, pero debe pedir confirmación antes de instalar o reiniciar.
